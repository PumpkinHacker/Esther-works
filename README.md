# Esther World 🐾

Welcome to Esther World, a fun animal adventure game!

## How to Publish

1. Download and extract the Esther World ZIP file.
2. Upload `index.html` to the root of your GitHub repository.
3. Make sure GitHub Pages is enabled in your repository settings.
4. Open your GitHub Pages website to play.

## Files

- `index.html` — The main game website.
- `README.md` — This project guide.

## Note

Keep a backup of a working version before replacing files. If the game gets stuck loading, check the browser console for JavaScript errors.
